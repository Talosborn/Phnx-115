#

**Terracotta Knight** is a 2D side-scrolling search action game built in Unity. Previously designated **Project Aleph**, it represents the efforts of a diverse team of undergraduate students currently enrolled at Utah State University. In its current state, Terracotta Knight does not constitute a complete game, and should be regarded as entertainment software for demonstrative purposes only.
