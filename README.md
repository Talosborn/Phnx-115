#

**Project Aleph** is a 2D side-scrolling search action game made with Unity by a diverse team of undergraduate students currently enrolled at Utah State University. It represents the efforts of a four-month collaboration and does not constitute a complete game, but should be regarded as entertainment software for demonstrative purposes only.
